元件到冷板熱阻鏈

從接面到冷板，找出每一段溫差與散熱瓶頸。

01元件與冷板

RθJC 必須對應實際散熱面，請查元件資料表。冷板溫度請填元件下方的表面溫度，不是冷卻液入口溫度。

02介面材料與熱阻

材料層採一維導熱 R = t/(kA)。填的是有效傳熱面積；擴散效應請另填熱阻。若供應商的 TIM 熱阻已含接觸熱阻，請避免重複加入。

03另一條散熱路徑

此值需代表獨立的「接面到環境完整路徑」，由模型或實驗取得。不要直接把資料表 RθJA 當成獨立 PCB 支路，也不要將 ΨJT 當作串聯熱阻。

模型範圍與熱參數選擇

未開啟並聯路徑時，假設全部元件損耗都流向冷板，將封裝、材料層、接觸與擴散熱阻串聯。這是單一主要散熱路徑的初估；多顆元件、板內熱耦合與冷板局部溫升需另外評估。

RθJC(top) 與 RθJC(bottom) 對應不同散熱面，請核對資料表的量測定義。ΨJT 為熱特性參數，不是真正熱阻，不可放入此串聯網路。RθJA 也受測試 PCB 與環境影響，不能直接當作新增的獨立並聯支路。

並聯模式假設兩條已知且互不重複的完整路徑，熱阻不隨溫度改變。冷板比接面高溫時可能出現反向熱流，工具保留正負號。允許冷板溫度是理想網路在指定接面上限時的代數結果，應搭配實際冷板、其他支路溫度與熱阻的可信範圍使用。

公式與計算流程
材料層 R = (t_mm/1000) / [k × (w_mm×h_mm/10⁶)]
R冷板路徑 = RθJC + ΣR材料 + R接觸 + R其他
單一路徑：Tj = T冷板 + P × R冷板路徑
並聯：Tj = (P + T冷板/R冷板路徑 + Ta/R另一支路) / (1/R冷板路徑 + 1/R另一支路)
Q冷板 = (Tj − T冷板) / R冷板路徑
Q另一支路 = (Tj − Ta) / R另一支路
各段 ΔT = Q冷板 × R該段；P = Q冷板 + Q另一支路
T冷板,允許 = Tj,max − [P − (Tj,max−Ta)/R另一支路] × R冷板路徑
單一路徑時刪去另一支路項目。

單一路徑的理論散熱能力：Pmax = (Tj,max − T冷板)/R冷板路徑；開啟並聯時另加 (Tj,max − Ta)/R另一支路。本工具顯示接面上限餘裕和允許冷板溫度，並以沿途溫差找出冷板路徑的主要瓶頸。
