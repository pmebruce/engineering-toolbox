    01 風扇 PQ 資料

    可直接貼 Excel 的兩欄；接受逗號、Tab 或空白。第一列可為欄名；請先把圖片曲線整理成數值。

    原始 PQ 為單顆風扇。並聯在相同壓差下加流量；串聯在相同流量下加壓差。

    02 濾網／阻抗資料

    同一流路

    僅當橫軸為面風速時，用迎風面積換算 Q。面積指有效迎風面，非濾材展開面積；改變面積不會縮放已輸入的流量曲線。

    濾材可能同時有線性與非線性阻抗，優先使用量測插值。平方擬合僅供近似與補點。

    03 系統與情境

    其他阻抗用平方律估算，與濾網壓降相加。若輸入的是完整系統阻抗，請設為 0，避免重複計入。

    同流量下放大濾網壓降，用來比較堵塞或較高阻抗情境；倍率是你設定的假設，不預測使用時間。

    公式、假設與資料來源

    工作點

    Δpfan(Q) = Δpfilter(Q) + Δpother(Q)

    所有交點皆列出。局部斜率判斷使用 d(Δpfan − Δpsystem)/dQ：負值標示為「恢復方向」，不代表已驗證動態穩定或失速。

    平方擬合

    K = Σ(Qᵢ² Δpᵢ) / Σ(Qᵢ⁴)

    通過原點的最小平方擬合；RMSE = √[Σ(KQᵢ² − Δpᵢ)² / n]。其他阻抗：Δp = Δpref × (Q/Qref)²。

    風扇合成與轉速

    並聯：Qtotal = nQ，壓差不變。串聯：Δptotal = nΔp，流量不變。

    轉速比例 r：Q′ = rQ；Δp′ = r²Δp。假設相同風扇、相同密度，未包含安裝效應。

    面風速與單位

    Q = v × A；A = WmmHmm / 10⁶。

    1 CFM = 0.0004719474432 m³/s；1 mmH₂O = 9.80665 Pa；1 inH₂O ≈ 249.08891 Pa。

    參考：ebm-papst：風扇性能與工作點、AMCA：風扇與系統曲線。工程估算需使用與實際條件一致的廠商或量測資料。
