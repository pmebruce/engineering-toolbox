模型範圍與讀取方式

結果是等溫外殼的平均表面溫度，不等於箱內空氣、元件接面或局部熱點溫度。模型假設全部發熱量最後經外殼的外部對流與輻射排出，未包含內部元件到箱殼的熱阻、通風、安裝支架導熱或日照。

外部環境為常壓、靜止空氣、開闊空間；各面視為獨立平板。底面關閉時同時略去其對流和輻射。各面流場互相干擾、狹縫與壁面遮蔽須另行校正。ε 預設值會受氧化、顏色、塗層與製程影響。

輻射假設所有有效表面對均勻大環境的視角因子 F = 1。若外殼不均溫、內部傳熱差，應以 CFD 或量測確認。

公式與計算流程
Q = Σ[hᵢ Aᵢ (Tₛ − Tₐ) + ε σ Aᵢ (Tₛ,K⁴ − Tᵣ,K⁴)]
Ra = g β |Tₛ − Tₐ| Lc³ / (ν α)；Pr = ν/α；h = Nu k/Lc
垂直面 Lc = 高度；水平面 Lc = 面積 / 周長
垂直面 Ra ≤ 10⁹：Nu = 0.68 + 0.67 Ra¼ / [1+(0.492/Pr)⁹⁄¹⁶]⁴⁄⁹
垂直面 Ra > 10⁹：Nu = {0.825 + 0.387 Ra⅙ / [1+(0.492/Pr)⁹⁄¹⁶]⁸⁄²⁷}²
熱面朝上：Nu = 0.54 Ra¼（Ra ≤ 10⁷）；0.15 Ra⅓（Ra > 10⁷）
熱面朝下：Nu = 0.27 Ra¼
冷面則交換水平面方向；σ = 5.670374419×10⁻⁸ W/(m²·K⁴)

使用二分法求解 Tₛ。空氣性質在膜溫 (Tₛ+Tₐ)/2 評估：ρ = p/(R T)、μ 採 Sutherland 式、k ≈ 0.0241(T/273.15)^0.9、Cp = 1006 J/(kg·K)、β = 1/T。性質近似適用膜溫 250–500 K；超出時顯示提醒。

垂直面關係式的建議 Ra 範圍為 10⁴–10¹³；熱面朝上為 10⁴–10¹¹；熱面朝下為 10⁵–10¹⁰。超出時仍顯示外推估值及提醒。上限附近的模式切換採分段式，曲線可能出現小幅不連續。
