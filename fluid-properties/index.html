流體物性查詢

選擇流體與溫度，查詢熱流計算需要的物理性質。

查詢條件

CFD 材料設定

複製單點報告可取得 SI 單位的 ρ、cₚ、k 與 μ。ν 是 μ／ρ，請依軟體欄位選用，避免把動力黏度與運動黏度混用。

僅帶入目前單點液體物性。接收工具會顯示查詢溫度與濃度。

本工具提供工程擬合值。EG／PG 為不含添加劑的水溶液模型，不能取代品牌冷卻液規格；不包含相變、濕空氣或高壓效應。

資料來源與計算說明

採用 CoolProp 開源不可壓縮流體資料中的擬合係數，在瀏覽器直接求值；不是完整 CoolProp 求解器或即時量測資料。係數快照：2026-11-03。

模型、範圍與濃度定義
  • 空氣：CoolProp INCOMP Air，參考 Lemmon 2000／2004；本工具範圍 −50～200°C。依海拔與查詢溫度，以乾空氣理想氣體式 ρ = p/(287.05·T) 計算密度。cₚ、k、μ 沿用溫度擬合，忽略此低壓範圍內的壓力影響。
  • 水：使用 CoolProp MEG 在 0 wt% 的純水端點，與 EG 濃度為 0 時一致；範圍 0～95°C。屬 Melinder 工程擬合，非 IAPWS 高精度水物性。
  • EG／PG：CoolProp MEG／MPG，參考 Melinder 2010；濃度 0～60 wt%。溫度下限取 −50°C 與模型預估冰點中較高者，上限 95°C。低於冰點時不提供液相物性。
  • 海拔以 NASA 對流層模型估算氣壓，並將 0 m 校準為 101.325 kPa。純水開放沸點依 IAPWS 飽和蒸氣壓關係反算。密閉回路應使用實際局部絕對壓力。
  • 液體採不可壓縮近似，忽略壓力對物性的影響；須確認實際系統維持單一液相。冰點是模型估值，不是保證防凍溫度。
  • 所有數值均為擬合結果，顯示位數不代表精度。表格區與單點區各自檢查範圍，切換條件後不會保留失效結果。
公式與原始資料

ρ、cₚ、k 使用中心化多項式；EG／PG 的 μ 使用多項式的指數，空氣 μ 使用來源的 exponential 公式。ν = μ／ρ；Pr = μcₚ／k；熱擴散率 α = k／(ρcₚ)；體積熱容 = ρcₚ。
