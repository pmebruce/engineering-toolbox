1. 散熱片尺寸與掃描範圍

H 填有鰭片區的垂直高度，不含下方的 MOSFET 安裝區。W 填鰭片伸出長度，L 沿水平風向。無鰭片基板區的換熱與熱擴散未計入。假設導風罩封住鰭片頂端，風從一端進入、另一端離開。掃描時固定 L、W、H 與鰭片厚度。

5. 計算公式與代入值

  1. 鰭片間距與流道 s = (H − N t)/(N − 1)，Aflow = (N − 1)sW，Dh = 2sW/(s + W)。
  2. 風量與壓降 v = Q/Aflow，Re = ρvDh/μ，ΔP = (f L/Dh + K)ρv²/2 + ΔPref(Q/Qref)²。固定風量與固定風速模式只計散熱片風道壓降。固定風速時以 Q = v·Aflow 換算風量，P–Q 模式用分段線性曲線求交點。層流 Darcy f 使用矩形風道 Poiseuille 數，紊流 f 使用光滑管 Petukhov 式。入口與出口 K 為合併估計。
  3. 換熱 h = Nu·kair/Dh，m = √(2h/kfin/t)，η = tanh(mW)/(mW)，Aeff = (N − 1)L(s + 2ηW)。層流採矩形風道充分發展定壁溫近似，紊流採 Gnielinski，Re 2300–4000 線性銜接。風罩絕熱、只有三側受熱，以四壁矩形關聯式近似。
  4. 溫度與瓦數 C = ρQcp，Rsa = 1/[C(1 − exp(−hAeff/C))]，Tb = Tin + P·Rsa，Tj,i = Tb + Pi(RθJC + RθCS)，Pmax = (Tj,limit − Tin)/(Rsa + 最大功率占比 × (RθJC + RθCS))。出口風溫為 Tin + P/C。

穩態、共用等溫基板、無旁通。未算基板擴散熱阻、局部熱點、入口換熱增強與輻射。固定空氣物性約 40 °C、海平面。封閉箱請填散熱片實際進風溫度。結果適用於尺寸篩選，可用 FloTHERM 或實測校核。
