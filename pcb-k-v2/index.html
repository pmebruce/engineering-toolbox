PCB 導熱率 V2

由板層堆疊估算 kx、ky、kz，再比較局部散熱孔區的穿板熱阻。

1. 材料與堆疊

範例為合成堆疊。銅厚輸入成品厚度，1 oz 約 35 µm。介質厚度請勿包含銅厚。

由上往下排列。窄螢幕可在表格內左右滑動查看所有欄位。

層序類型厚度
µm		覆銅率

W/m·K		走線拓撲操作

「連通於 X／Y」代表沿該方向有理想連續銅路。覆銅率相同，走線方向不同，面內 k 可能差很多。拓撲未知時顯示串聯至並聯的模型區間。

2. 散熱孔區

以局部等效區面積計算，例如元件散熱焊盤下方。只計從區域上表面貫穿至下表面的通孔。

孔芯 0.026 為室溫空氣的工程近似，可依填孔材料修改。穿板熱流是實際流經這個區域的熱量。

3. 等效材料與熱阻

FloTHERM／XT 建模時，X、Y 對應板面，Z 為板厚方向。整板可用無孔結果作初估。局部散熱孔區可使用含孔 kz，面內值沿用未計孔壁的堆疊估算。若已建出孔壁實體，請避免重複計入。

公式、適用條件與公開來源
  • 每層銅佔比 f。並聯 k = f·kCu + (1−f)·kd。串聯 k = 1 / [f/kCu + (1−f)/kd]。連續雙向銅路使用並聯近似。單向銅路沿走線取並聯，垂直走線取串聯。
  • 板面按各層厚度加權平均。Z 向先以面積並聯近似每一銅層，再以厚度串聯各層。此模型假定層間能以均化後的截面交換熱流。
  • 孔區採並聯熱導。從原板面積扣除孔外徑占用面積，再加上環形孔壁與孔芯的熱導。G = [kz·A剩餘 + k孔壁·A孔壁 + k孔芯·A孔芯]/板厚。R = 1/G，ΔT = Q·R。
  • 孔區結果假定兩端近似等溫且所有孔壁都參與導熱。局部熱擴散、焊料與介面熱阻、盲埋孔、熱焊盤細頸與外部對流需另建模型。覆銅率與方向由使用者提供。
  • Isola 370HR 公開規格提供 0.4 W/m·K 典型值。範例暫將其視為各向同性。
  • Copper Development Association C11000提供室溫銅材參考值，換算約 391 W/m·K。電鍍銅實際值可自行填寫。
  • Creating PCB Thermal Conductivity Maps Using Image Processing公開作者文章，說明方向性串並聯均化。
  • Texas Instruments SLVA959 §2.5提供通孔環形截面熱阻的計算依據。
