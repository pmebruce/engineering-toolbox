材料參數

02　接點損耗

10 μΩ 是操作示例，不是螺栓接點的通用值。請使用實測或供應商資料，並填入工作溫度下的接點電阻；切換材料時保留此輸入供同條件比較。實際接點電阻請依接合材料與表面處理確認。

計算方式與適用範圍

ρ(T) = ρ₂₀ [1 + α₂₀(T − 20)]
R本體,單支 = ρ(T) L / A
I單支 = I總 / n
R支路 = R本體,單支 + 接點數 × R接點
R等效 = R支路 / n
P總 = I總² R等效；ΔV = I總 R等效

穩態模式以單一熱節點反覆計算排體溫度與損耗，估算匯流排本體代表溫度。接點電阻固定，局部熱點與允許載流量需另行評估。等截面估算不解析孔邊、彎角、接點的三維電流集中；不包含交流集膚、鄰近效應與磁性損耗。脈動或交流請另外評估。

材料參數與散熱公式參考 Copper for Busbars — Guidance for Design and Installation與 Energex STNW3014 表 3。線性溫度修正本版限 −50～200°C；材料參數應與使用範圍相符。
