# 銅排損耗計算器 / Busbar Loss

零相依、單一 index.html 的獨立前端工具。可直接以瀏覽器開啟，或將此目錄部署為獨立 Cloudflare Pages 專案（無建置命令，輸出目錄為此目錄）。目前掛在 engineering-toolbox/busbar-loss/。

## 功能

- 等截面直流銅排電阻、壓降、I²R 本體損耗。
- 指定銅溫的線性電阻率修正；材料參數可修改。
- 相同支路理想平均並聯分流；接點電阻按每支路串聯接點數計算。
- 每支銅排本體、每接點與全部支路損耗分列；輸出 W、W/m³、W/mm³。
- 電流敏感度表、複製報告、CSV、列印、裝置本機保存輸入。

## 限制

不預測溫升／載流量，不解析孔洞、彎角、局部電流集中，不計 AC 集膚、鄰近效應與磁性損耗。溫度輸入範圍 −50～200°C。去回兩段屬於串聯，不應填成兩支並聯。接點電阻使用工作溫度值，不套銅溫度係數。預設 10 μΩ 僅為示例。

若 XT 已計算焦耳熱，勿再加入同一份損耗。

## 參考與檢核

材料預設 100% IACS 銅：ρ20=0.017241 Ω·mm²/m，α20=0.00393 /°C。參考 Copper Development Association / Copper for Busbars：https://kupfer.de/wp-content/uploads/2019/11/Copper-for-Busbars.pdf

已對實作計算函式完成語法及數值檢核：1000×50×10 mm、1000 A、20°C、無接點：34.482 W；相同兩支並聯、總電流不變：17.241 W；單支增加兩個 10 μΩ 接點：接點合計 20 W；80°C 本體損耗為20°C的1.2358倍。亦檢核零電流及無效尺寸拒絕。
